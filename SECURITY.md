# Security

Please report security problems privately: open this repository's **Security** tab and choose
**Report a vulnerability**. Include the Ottsel commit or release, the device and OS version, and the steps
to reproduce. You will get a reply on that report.

Ottsel's builds run only on your own Mac and devices, and the apps you build are personal. Never attach
game data, disc images, ROMs, extracted files, a built app, saves, signing certificates or provisioning
profiles to a report or an issue.

Problems in OpenGOAL itself belong with [OpenGOAL](https://github.com/open-goal/jak-project); problems in
PadMint belong with [PadMint](https://github.com/chrissotraidis/padmint).
