## Findings requiring redirection
1. **P1 — production baseline is diagnostic.** `src/shell/metal_shell.mm:85` returns `float4(saturate(texel.rgb),1)` unconditionally. Modulation and alpha-test lines 86–100 are bypassed for shared Direct/Sprite/Sky pipelines. A no-trigger launch is still altered. Preserve the diff, then surgically restore the material path before comparisons.
2. **P1 — MERC loses homogeneous W.** `metal_gfx.mm:1722–1747` skins only xyz; `metal_shell.mm:146–149` assumes W=+1. Desktop `out/jak-project/game/graphics/opengl_renderer/shaders/merc2.vert:59–73` skins the full negative vec4. Affine normalized weights give W=−1, not +1. Preserve actual W, including non-affine inputs.
   BOT59's depth-mode change (`metal_shell.mm:1387`) masks this: with its recorded camera and skin.z=−40000, oracle Metal NDC z≈0.025556; current mode 0≈−0.025594; current shipping mode 1≈0.474406. This is a mathematical counterexample, not yet a runtime fix. BOT59's “z_world−2” derivation is invalid; its visibility observations remain useful.
3. **P1 — pending vertex buffers can be recycled.** `metal_shell.mm:2497–2519` retires every borrowed buffer with the current command buffer, including a producer append after the Direct snapshot at 2081. That batch survives tagged erasure but its bytes may be overwritten before the next draw. Strong references preserve objects, not byte immutability. This is a concrete possible interleaving, not attribution of a particular crash.
4. **P1 — Sky drops unseen batches.** Snapshot at `metal_shell.mm:1584`, whole-store clear at 2352: an append between them is erased without drawing. Use captured tags/ownership, not a later whole clear. The main presentation loop and GOAL boot thread are separate (`main.cpp:921,1155–1163`).
5. **P1 — regressions and reconstructable source diverged.** Policy `mobile_generic_policy.h:71` accepts 12/68; `out/jak-project/test/test_platform_input.cpp:287–288` expects false. The current malformed-link predicate/test exists in nested source but is absent from `patches/h3-jak1-host-boot.patch`; its old unsigned size check differs. Historical green tests do not validate the current tree.
6. **P1 — crash closure needs direct evidence.** Encoder RAII and RGBA validation exist; the August 22 crash report calls its live check bounded non-reproduction. Add a normal/exception/exactly-once guard regression, retain the malformed-link regression in reproducible patches, and run them before a new renderer round. Do not turn “fault log empty” into a root-cause proof.
7. **P2 — Direct STQ contract differs.** CPU divides S/Q at each vertex (`metal_gfx.mm:3267–3269`); desktop interpolates STQ then divides in the fragment (`direct_basic_textured.frag:54–58`). At an edge midpoint, (S,Q)=(0,1),(2,2) gives 2/3 on desktop versus 1/2 on mobile. Preserve FST separately and fractional UV texels; this does not establish the missing-sky root cause.
8. **P1 — route and evidence identity drift.** BOT56 has `scene-level=village1` during the title menu; BOT60 has `GAMEPLAY enter village1` followed by `intro-start`. A camera pan, scene hash or residency counter cannot prove target control. Record frontend/cutscene/target state plus visible move/jump/release in the same run.
9. **P2 — the diagnostic A/B is not isolated.** Debug-fill also filters small textures, skips bindings and adds reference draws (`metal_shell.mm:1657–1780`); sky-end takes a second mutable snapshot (`2230`). Different final pixels do not isolate texture binding. Use one immutable batch, one state, one changed variable and successful GPU completion.
10. **P2 — current reading order contradicts itself.** INDEX points to BOT33, STATUS to BOT43, tails to later prompts; BOT66 renames I3/P1. A single recovery loop and dated board must supersede these histories without deleting them.

## Refuted conclusions and bounded hypotheses
- The claimed extra Direct nx/ny scale is algebraically false: `2*(8*(gx−.5)+.5)−1=16*(gx−.5)` and `1−2*(.5−.5*clip_y)=clip_y`. `push_vertex` stores raw u32 x/y and the sprite inverse multiplies normalized coordinates by UINT32_MAX; the capture divide is appropriate. Logged SKYVERT positions are already NDC and must not be transformed again. This does not isolate texture sampling or exonerate buffer ownership.
- A zero VU1/raster counter does not invalidate native FR3 rendering. BOT64's proposed desktop-mips2c world-runner rewrite was corrected by BOT65. Continue source-backed contracts, not an engine rewrite.
- “Only sky remains,” “texture binding proved broken,” “all frames are gameplay,” and “four probes caused the GOAL fault” exceed their evidence. Preserve observations; test causes separately.
- CPU `OttselRaster::to_screen` is not a Direct coordinate oracle: its x=gx*640 differs from the actual desktop shader viewport mapping. Use the actual renderer/shader and matched packets.
