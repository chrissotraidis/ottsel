## The current blocker: state-symbol mislink (DIAGNOSED, not fixed)

See `docs/evidence/S2/s21-bot12-state-mislink.md` for the full analysis.
Verified facts:

1. `intern_from_c("target-continue")` -> value **0x42b4000** (shrub-work's
   zeroed static region).  The real target states are at 0x4624074 /
   0x46252d4 in target-death's static data; two of the three target state
   symbols resolve correctly, `target-continue` does not.
2. The cross-segment ADRP+ADD patch in `cross_seg_dist_link_v3`
   (`game/kernel/jak1/klink.cpp`) is CORRECT (verified with the temporary
   `OTTSEL LINKSTAT` diagnostic).
3. The `(set! state-sym state)` symbol-set stores the state address via a
   `(sym - s7)` slot in the TRANSIENT top-level segment's static data
   (0x3ab4000..0x3ab4068; the `target-continue` slot is at 0x3ab4014),
   which every subsequent object's top-level overwrites.  The slots are
   written at link time and read during the object's own top-level, so they
   should be valid then -- yet the resulting value is garbage.
