## Gotchas learned

- REGLIST XYZF2 register = x(16)|y(16)|z(24)|f(8); PACKED = x(4) y(4) z/f(8).
- The direct bucket data is behind VIF DIRECT codes; walk VIF words + GIF
  packets like DirectRenderer::render_vif (the naive GifTag-per-transfer read
  produces garbage nloop=0x7fff packets).
- Texture data is NOT at the tpage segment block linearly and there is no
  IMAGE payload path in this port (PC_PORT GOAL skips the GS upload DMA; the
  upload-now! hook receives the tpage pointer and the data is pre-scrambled).
- tpage 1609 is `demo5j`, not the title backdrop; title-vis uses tpages
  397/415/416/1499 + tpage 1609 for overlays (TIT.DGO: static-screen.o,
  title-obs.o, tpage-1609.go, tpage-416.go, ...).
