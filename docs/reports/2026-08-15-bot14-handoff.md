  was never linked -- the raw ISO TIT.DGO's PS2-v3 GOAL objects were skipped

     (0x4c414f47) as a linkable block (v2/v4 tag -1 unchanged).

     synchronously (the goal-side multi-frame `linking`-flag resume path
     never fires for the v3 DGO objects on this port).
